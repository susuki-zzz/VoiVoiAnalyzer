# Privacy Policy

## VoiVoiAnalyzer Privacy Commitment

VoiVoiAnalyzer is designed with privacy as a core principle.

### Audio Data Privacy

- **No Audio Transmission**: Your audio is NEVER transmitted over the network
- **Local Processing Only**: All voice analysis happens entirely on your local machine
- **RAM-Only Live Mode**: Live analysis data is kept in RAM only
- **Manual Save Control**: Audio is only saved when you explicitly choose to save it
- **Optional Auto-Save**: Auto-save on stop can be enabled in settings (disabled by default)

### AI Coach Feature (Optional)

If you choose to use the AI Coach feature:
- **Metrics Only**: Only analyzed metrics are sent (F0, RMS, CPP, HNR, etc.)
- **No Raw Audio**: Your voice recordings are NEVER sent to AI services
- **Opt-in Only**: This feature is disabled by default and requires explicit activation
- **Data Minimization**: Only the minimum necessary analysis results are transmitted

### Data Storage

- **Local Storage Only**: All data remains on your computer
- **User Control**: You decide what to save and when
- **No Telemetry**: No usage data is collected or transmitted
- **No Analytics**: No analytics or tracking

### Open Source Transparency

- **Auditable Code**: Full source code is available for review
- **Community Trust**: Open source allows independent verification of privacy claims
- **GPLv3 for App**: GUI application is licensed under GPLv3
- **MIT for Core**: Core library is licensed under permissive MIT license

### Your Rights

- You own all your data
- You control all privacy settings
- You can use the software completely offline
- No account or registration required

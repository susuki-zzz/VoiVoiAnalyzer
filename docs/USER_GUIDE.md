# VoiVoiAnalyzer ユーザー操作ガイド

このガイドは、VoiVoiAnalyzer を使ってリアルタイム音声トレーニングを行うユーザー向けの操作手順をまとめています。主要機能の使い方、初期設定、トラブルシューティングを順に解説します。

### クイックスタートチェックリスト

1. 初回起動時に表示されるセットアップガイドに従ってマイク権限を付与します。
2. **Audio Settings** から入力デバイスとサンプルレート（推奨 48 kHz）を選択します。
3. 練習したい目的に合わせてプリセットを 1 つ選択し、`Start Session` を押して録音を開始します。
4. メインメーターとヒートマップでリアルタイムフィードバックを確認しながらトレーニングします。
5. セッション終了後は `Save` から WAV / CSV / JSON をまとめてエクスポートし、履歴として保存します。

## 1. 主要機能の概要

### 音声解析
- **基本指標**: F0（ピッチ）、RMS/ピーク、CPP、HNR、スペクトルチルト、/s/ セントロイドをリアルタイムで計測します。
- **音声活動検出 (VAD)**: 発声区間を検出し、発話速度やポーズ比率を算出します。
- **プリセット**: 4 つのプリセット（Natural Conversation / Phone Training / Resonance Focus / Diagnostic）が用意され、分析対象をすぐに切り替えられます。

### 可視化と記録
- **メーター表示**: 主要なメトリクスをゲージやバーで表示し、ターゲットレンジとの比較ができます。
- **ヒートマップ**: F0 や RMS の時系列をヒートマップで追跡し、安定度を確認できます。
- **セッション記録**: WAV（32-bit float）とメトリクス（CSV/Parquet）、セッション設定（JSON）を保存できます。

### AI コーチ（オプション）
- **アドバイス生成**: 収集したメトリクスの統計値のみをクラウドに送信し、ボイストレーニングのアドバイスを取得します。
- **プライバシー**: 生の音声データは送信されません。API キーは Windows では DPAPI で安全に保存されます。

## 2. 初期設定とワークフロー

### スタートアップ手順
1. アプリを起動し、メイン画面左上の **オーディオ設定（Audio Settings）** を開きます。
2. 入出力デバイスを選択し、推奨サンプルレート（48 kHz）とバッファサイズ（既定値）を確認します。
3. 使用シナリオに合わせてプリセットを選択します。
4. 録音を開始するとメトリクスとヒートマップがリアルタイム更新されます。
5. セッションが完了したら **保存（Save）** を押してデータを保存します（自動保存を有効にした場合は停止時に自動保存されます）。

#### プラットフォーム別セットアップ

- **Windows**: `build.bat` を実行すると必要な Visual Studio 構成と JUCE 依存関係が自動的に解決されます。音量ミキサーでマイクがミュートされていないか確認してください。
- **macOS**: 初回起動で表示されるマイクアクセス許可ダイアログに必ず応答してください。`Audio MIDI 設定` アプリで入力サンプルレートを 48 kHz に揃えると解析結果が安定します。
- **Linux (ALSA)**: `build.sh` で依存パッケージをインストール後、`alsamixer` でキャプチャデバイスのレベルとミュート状態を確認します。PulseAudio / PipeWire 使用環境では `pavucontrol` からデバイスを固定してください。

#### オーディオ診断と推奨ワークフロー

- **レベルメーターのキャリブレーション**: セッション前にマイクへ一定の声量で発声し、RMS が -18 ～ -12 dBFS 付近になるよう入力ゲインを調整します。
- **プリセットのカスタマイズ**: 設定画面からプリセットを複製し、自分の目標ピッチ帯域やヒートマップ範囲を微調整できます。カスタムプリセットは自動保存対象に含まれます。
- **セッションノート**: メイン画面右上のノートフィールドに練習内容を記録すると、保存された `session.json` にメタデータとして残ります。

### 設定メニュー
- **オーディオ（Audio）**: サンプルレート、バッファサイズ、最大録音時間を調整します。
- **プリプロセスチェーン（Preprocess Chain）**: モニター／録音出力に適用するエフェクトを設定します（分析には影響しません）。
- **自動保存（Autosave）**: セッション終了時に自動保存するか選択します。
- **AI コーチ（AI Coach）**: API キーの入力、最小応答間隔の設定、機能の有効／無効を切り替えます。

## 3. 詳細機能

### プリセットごとの特徴
- **Natural Conversation**: 日常会話向け。ピッチと声質のバランス改善に最適。
- **Phone Training**: VoIP 通話を想定した明瞭度向上が目的。中高域のエネルギーをチェック。
- **Resonance Focus**: 共鳴バランスに着目。スペクトルチルトと /s/ セントロイドを重点表示。
- **Diagnostic**: すべての指標を表示し、詳細な評価やレポート作成に向きます。

### ヒートマップとビジュアルツールの活用
- **ズーム & スクラブ**: Shift + ドラッグで任意区間にズームし、マウスホイールで縮尺を滑らかに変更できます。ズーム時はタイムスタンプ軸が自動的に再計算されます。
- **高解像度モード**: `Resolution` トグルをオンにすると 1 カラム 1 サンプル描画になり、ピッチ揺れや瞬間的なピークを確認しやすくなります。
- **PNG エクスポート**: `Export Heatmap` から 16:9 / 4:3 など任意解像度の画像を出力できます。プレゼン資料やレポートへの添付に便利です。

### メトリクスの読み取り
- **F0 ゲージ**: ガイドバンドに対して音高が上下すると色でフィードバックします。
- **CPP/HNR**: 声の明瞭度や倍音成分の多さを示す指標。プリセットごとの目安値を参考にします。
- **発話速度／ポーズ比率（Speech Rate / Pause）**: 発話テンポの改善や練習目標の設定に利用します。

### セッション管理
- **手動保存（Manual Save）**: 必要なタイミングで手動保存し、記録ファイルを任意の場所に書き出します。
- **セッション JSON**: 解析パラメータやプリセット情報を含むため、再現性の高い練習記録が可能です。
- **レビュータイムライン**: `History` タブから過去セッションのメトリクス履歴を重ね合わせ、ベースラインとの差異を視覚化できます。UI 上で非表示にしたセッションでも、エクスポートした JSON には保持されます。
- **オフライン解析への移行**: 長時間録音を解析したい場合は `yvc_offline` を使用し、最大 3 時間の WAV を一括処理できます。`docs/BUILD.md` のオフラインツール節を参照してください。

## 4. トラブルシューティング

| 症状 | 原因の例 | 対処 |
|------|-----------|------|
| 音が途切れる／レイテンシが大きい | オーディオデバイスのバッファ不足、CPU 使用率の増加 | バッファサイズを 1 段階大きくする、不要なアプリを終了する、プリセットをライト／ノーマルに切り替える |
| 入力が認識されない | デバイス設定や権限不足 | OS のサウンド設定でマイクが選択されているか確認し、アプリのマイク権限を許可する |
| 保存ファイルが見当たらない | 保存先の誤指定、自動保存の無効化 | 保存ダイアログのパスを確認し、必要に応じて自動保存を有効にする |
| AI コーチの応答がない | API キー未設定、最小間隔が長すぎる、ネットワークの問題 | 設定メニューで API キーを再確認し、最小間隔を短く設定、ネットワーク接続を確認する |
| Linux で GUI が起動しない | X11/Wayland 依存パッケージ不足、ヘッドレス環境 | `sudo apt install --no-install-recommends libx11-dev libxcomposite-dev libxcursor-dev libxinerama-dev libfreetype6-dev` を実行し、必要に応じて `xvfb-run` で起動する |
| macOS でマイクレベルが低い | システム設定の自動入力調整や外部インターフェースのゲイン不足 | `システム設定 > サウンド > 入力` の自動調整を無効にし、オーディオインターフェース側で十分なゲインを確保する |

## 5. よくある質問

- **Q. どのプリセットを選べばよいですか？**  
  初めての場合は *Natural Conversation* から始め、目的に応じて切り替えてください。

- **Q. 設定を元に戻すには？**  
  設定画面で *Reset to Default* を選択すると初期状態に戻ります。

- **Q. 保存したメトリクスを他ツールで解析できますか？**  
  CSV/Parquet 形式で出力されるため、Excel や Python（pandas）などで読み込めます。
